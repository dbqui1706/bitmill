Cấu hình Google Cloud Storage (GCS) CORS

      

        Trình duyệt web yêu cầu bucket GCS cho phép các phương thức HTTP PUT, GET, HEAD và đọc các header phản hồi khi tải lên. Cấu hình này đã được áp dụng tự động cho gs://bitmill-raw-videos và gs://bitmill-processed-videos.
      

      
[
  {
    "origin": ["*"],
    "method": ["GET", "PUT", "POST", "HEAD", "DELETE", "OPTIONS"],
    "responseHeader": ["Content-Type", "ETag", "etag", "Range", "Accept-Ranges", "Content-Range", "Access-Control-Allow-Origin"],
    "maxAgeSeconds": 3600
  }
]

      
Áp dụng thủ công qua gcloud CLI:

      
gcloud storage buckets update gs://bitmill-raw-videos --cors-file=cors.json
gcloud storage buckets update gs://bitmill-processed-videos --cors-file=cors.json
