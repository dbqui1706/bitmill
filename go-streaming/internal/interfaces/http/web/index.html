Cấu hình Cloudflare R2 CORS

Trình duyệt web yêu cầu Cloudflare R2 phải cho phép đọc header ETag khi gửi HTTP PUT. Nếu gặp lỗi CORS, vui lòng dán JSON sau vào:
Cloudflare Dashboard > R2 > bitmill-raw-videos > Settings > CORS Policy: 

[
  {
    "AllowedOrigins": ["*"],
    "AllowedMethods": ["GET", "PUT", "POST", "HEAD", "DELETE"],
    "AllowedHeaders": ["*"],
    "ExposeHeaders": ["ETag", "etag", "Content-Length"]
  }
]
